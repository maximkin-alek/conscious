### 3. Улучшения/кодстайл

**Улучшение 1: Использование dayjs вместо Date.now()**
- **Место**: Строки 18, 30
- **Что не так**: Согласно `.cursorrules`, для работы с датами нужно использовать dayjs. В тестах используется `Date.now()`.
- **Как исправить**: 
```javascript
import dayjs from 'dayjs'
// ...
const deadline = dayjs().add(1, 'minute').valueOf()
```

**Улучшение 2: Более точные проверки для null**
- **Место**: Строки 13, 26, 37
- **Что не так**: Используется `.toBe(null)`, что корректно, но можно использовать `.toBeNull()` для лучшей читаемости.
- **Как исправить**: Заменить `.toBe(null)` на `.toBeNull()`.

**Улучшение 3: Проверка типа данных**
- **Место**: Тест "startTimer sets deadlineMs and starts timer"
- **Что не так**: Нет проверки, что `deadlineMs` является числом.
- **Как исправить**: Добавить `expect(typeof store.deadlineMs).toBe('number')`.

**Улучшение 4: Константы для тестовых данных**
- **Место**: Строки 18, 30
- **Что не так**: Магические числа `60000` в коде.
- **Как исправить**: Вынести в константы:
```javascript
const ONE_MINUTE_MS = 60000
const deadline = Date.now() + ONE_MINUTE_MS
```

**Улучшение 5: Описательные названия тестов**
- **Место**: Названия тестов
- **Что не так**: Названия можно сделать более информативными.
- **Как исправить**: 
  - "has correct initial state" → "should have correct initial state"
  - "startTimer sets deadlineMs and starts timer" → "should set deadlineMs and start timer when startTimer is called"
  - "stopTimer clears deadlineMs and stops timer" → "should clear deadlineMs and stop timer when stopTimer is called"
